# Python-project---Drone-Rescue-Game
Project Python réalisé dans le cadre de ma première année d'école d'ingénieur. Ceci est un jeu de drones et de survivants. Le joueur 1 contrôle 6 drones pendant que le joueur 2 déplace 4 tempêtes. Le but du joueur 1 est de ramener tous les survivants à la base, sans manquer de batterie. Le but du joueur 2 est de toucher les drones pour les désactiver pendant deux tours. Le jeu se joue sur une grille 12 *12, dont le contenu est représenté par : D = drone, numérotés de D1 à D6, H = Hôpital, B = Bâtiment dont le nombre varie aléatoirement entre 8 et 16, S = Survivants au nombre de 10, T = Tempêtes numérotées de T1 à T4 et une case vide.
