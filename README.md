# Python-project---Drone-Rescue-Game
Python project completed as part of my first year of engineering school. This is a drone and survivor game. The game is played on a 12x12 grid, the contents of which are represented by: D = drones, numbered from D1 to D6, H = Hospital, B = Buildings (numbered randomly between 8 and 16), S = Survivors (10), T = Storms ( T1 to T4) and one empty space
